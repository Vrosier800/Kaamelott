# 🏰 Jeu de citations Kaamelott
Une application web ludique sur l'univers de Kaamelott : une citation est affichée, et le joueur doit deviner quel personnage l’a prononcée.

Développée en TypeScript et SCSS, cette application frontend ne nécessite pas de backend.

## 🧱 Stack technique
Langage principal : TypeScript

Styles : SCSS

Type de projet : Application web 100% frontend

Données : Citations stockées localement (Objet TypeScript)

# 🎮 Fonctionnalités
Citation affichée aléatoirement

Liste de quatres personnages pour sélectionner l’auteur

Affichage du score en temps réél et du résultat en fin de partie

Interface légère et réactive, inspirée de l’univers de Kaamelott
